DIAMOND ENGINE
C++20 · Vulkan RHI · ECS · Jolt Physics
4K · 75+ FPS in Sponza with hardware RT reflections + DDGI — RTX 4070 / Ryzen 7 7700X

A C++20 game engine with a Vulkan renderer, ECS architecture, physics-driven characters, and a full editor toolchain.

C++20 Vulkan EnTT / ECS Jolt Physics Hardware Ray Tracing ImGui Editor
Github Repo
  • Architected a deferred Vulkan renderer behind a backend-agnostic RHI and a topologically-sorted render graph, featuring hardware ray-traced reflections, DDGI global illumination, SSGI/SSR, GTAO, cascaded and point shadows, TAA, and PBR materials, with graceful screen-space fallbacks for non-RT hardware.
  • Designed the engine around an EnTT entity-component-system, choosing plain data components over per-entity script objects so systems sweep contiguous memory pools with no pointer chasing or virtual dispatch, with one macro registering a new component type into the inspector and serializer.
  • Exposed gameplay through native C++ scripting where a single header pairs a component struct with the system that ticks it, and self-registering macros grant that component inspector UI, JSON save and load, and an editor add-component entry without touching a central application file.
  • Authored a user friendly Physics API over Jolt Physics and engineered a physics-driven character system with ragdolls, joint motors, and two-bone IK, culminating in a SIMBICON-inspired procedural locomotion controller that walks entirely through physics forces, sampling no animation clips and teleporting no transforms.
  • Built an asset pipeline with a registry that deduplicates textures and meshes in VRAM, hot reload that swaps assets in place without invalidating references, prefabs, BC7 texture cooking, and a one-click standalone packager.
  • Developed a full ImGui editor with hierarchy, inspector, content browser, and animator graph panels, transform gizmos, viewport picking, undo/redo, and play/pause/stop with snapshot-based scene restore.
  • Instrumented the engine with an in-editor profiler that pairs Vulkan timestamp queries for per-pass GPU timings with zero-allocation CPU scope timers applied automatically to every gameplay system, reporting smoothed averages beside rolling peaks so single-frame hitches stay visible.
  • Implemented the supporting game layer, including 3D positional audio with a bus mixer, a particle system with authorable emission shapes, input action mapping across four gamepads, and an anchor-based runtime UI system.
